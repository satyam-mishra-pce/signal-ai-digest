# Signal AI Digest

A static, Twitter-style digest of AI discussions from a curated set of X accounts.

## Views

- **Digest:** nine consolidated AI themes with source threads.
- **Weekly:** AI-signal digests from January through August 2026.
- **Search:** keyword, author, and post-type search across 17,595 collected posts.

Every synthesis links back to its supporting posts on X.

## Local development

```bash
python3 -m http.server 4173
```

Open <http://127.0.0.1:4173>.
